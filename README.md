🎵 Music Player App
A simple and intuitive Music Player app built using Android Studio. This app allows users to play, pause, stop, and navigate through songs with ease. It's designed for a smooth and user-friendly experience.

📱 Features
🎧 Play, Pause, and Stop audio

⏭️ Next and Previous track navigation

🎶 Displays currently playing track

🕹️ Easy-to-use interface with ImageButtons

📂 Local music file support

🔁 Loop and shuffle features (optional/customizable)

🛠️ Tech Stack
Language: Java

Platform: Android Studio

Media Playback: MediaPlayer class

UI: XML Layouts

🔧 How to Run
Clone or download the repository.

Open the project in Android Studio.

Place your .mp3 files in the assets folder.

Run the app on an emulator or physical Android device.
